# Audits

Dated snapshots of the parity work: what was compared, what was found, and the evidence. Files here
are **read-only** once committed — a newer audit supersedes an older one instead of editing it. Use
the date in the filename (`YYYY-MM-DD-topic.md`) and link the PR or commit the numbers came from.

The current work queue is [`../gpui-egui-parity-plan.md`](../gpui-egui-parity-plan.md); an audit is
input to it, not a second status board.
