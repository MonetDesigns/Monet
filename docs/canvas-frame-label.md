> 2026-11-22 按设计稿 Groups 231 / 232 / 234 / 235 落地。本文只记**几何与颜色结论**，
> 代码在 `crates/ui-gpui/src/canvas/frame_labels.rs`（名称与图标槽）、
> `crates/ui-gpui/src/canvas/overlays.rs`（尺寸框）、`crates/ui-gpui/src/lib.rs`
> （`label_slot_press`：图标槽的点击）。

## 1. 名称文字

| 项 | 值 |
|---|---|
| 文字框底边 → 对象上边缘 | **7** |
| 字号 / 字重 | 11 pt / Regular（`regular(11.0)`） |
| 左端 | 与对象上边缘的起点角对齐（`label_edge` 的 `corner`，旋转帧跟随边） |
| 组件 / 组件集前缀 | `❖` + 一个空格（`COMPONENT_MARK = "\u{2756} "`） |
| 改名时 | 只显示原名：前缀由静态绘制加，内联输入框里是文档里的真名，所以自动没有前缀 |

颜色（`label_ink`）：

| 状态 | 颜色 |
|---|---|
| 未选中 / 常态 / 悬停 | 灰：浅色主题黑 26%（`from_black_alpha(67)`），深色主题同比例白 |
| 选中，普通帧 | 强调色 `app.accent()`（浅色页面上即更深一档，蓝 = `#007AE5`） |
| 选中，组件 / 组件集 | `#8638E5` |
| 选中，插槽 | `#FF24BD` |
| 选中，图标层 | `#FFB34D` |

## 2. 尺寸框（选中框下方）

| 项 | 值 |
|---|---|
| 顶边 | 对象下边缘 + **7** |
| 水平 | 与对象水平居中 |
| 内边距 | 左右各 6、上下各 2 → 11 pt 文字时约 61×17 |

## 3. 名称行右侧的两个 16×16 图标槽

两个槽都**水平右对齐到对象右边缘**，不跟随名称文字的长度：

| 项 | 值 |
|---|---|
| 槽尺寸 | **16 × 16** |
| 最右槽（①）的右边缘 | 对象右边缘 **+ 2** |
| 槽顶边 | 对象上边缘 **− 6**（槽底因此压进对象 10） |
| 两槽间距 | **2** |
| ② 的左边缘 | 对象右边缘 − 30（= ① 左边 − 2 − 16），顶边同 ① |
| 常态背景 | 透明 |

- **① 开发状态槽**（已做）：无状态时只有一枚灰色代码图标，点击 = 置 `devStatus: readyForDev`
  （底色变绿 `#087D4F`、圆角 3、白图标）；已有状态时再点，在槽下方 **6** 弹出下拉菜单，
  菜单与槽水平居中，两项：`在开发模式中打开`（选中该对象 + 右栏切到开发）、`移除状态`
  （`devStatus: none`）。状态为 `Changed` / `Completed` 时底色分别是 `#A75B00` / `#6E6E73`。
- **② 预留位**（**未做**）：位置如上表，本轮不画内容、不接点击。以后要做时直接用
  `frame_labels::name_slots(x1, y0)[1]`，别重新量设计稿。
- 槽只在对象**选中**时绘制（有状态的除外，它一直显示底色）；未选中时对象右上角不留可点区域，
  免得抢走右上角 8×8 缩放手柄的按下（`slot_at` 里手柄那一小块永远让给手柄）。
- 已知限制：旋转帧的标签保持水平（GPUI 不能整体旋转已画出的图元），槽按对象包围盒定位，
  不随旋转走。

| 项 | 值 |
|---|---|
