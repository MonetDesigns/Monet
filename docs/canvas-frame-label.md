# 画布名称标签 / 尺寸框 / 名称行图标槽

> 2026-11-22 按设计稿 Groups 231 / 232 / 234 / 235 落地。本文只记**几何与颜色结论**，
> 代码在 `crates/ui-gpui/src/canvas/frame_labels.rs`（名称与图标槽）、
> `crates/ui-gpui/src/canvas/overlays.rs`（尺寸框）、`crates/ui-gpui/src/lib.rs`
> （`label_slot_press`：图标槽的点击）。

## 1. 名称文字

| 项 | 值 |
|---|---|
| 文字框底边 → 对象上边缘 | **7** |
| 字号 / 字重 | 11 pt / Regular（`regular(11.0)`） |
| 左端 | 与对象上边缘的起点角对齐（`label_edge` 的 `corner`，旋转帧跟随边） |
| 过长时 | 逐字截断 + 末尾 `…`，可用宽度**不设下限**（`fit_with` 只夹到 1pt），能一路缩到只剩 `…` |
| 撞上右侧图标 | 用**原始名称文字**（未截断、含前缀）的实际宽度判断：一旦延伸到状态槽范围，就省略**图标**（不画、不接点击、不参与 hover 轮廓），名称照常画。短名称则图标照常显示 |
| 悬停名称文字 | 不显示三个点（只有状态按钮自身在已置标签后悬停才换省略号字形） |
| 组件 / 组件集前缀 | `❖` + 一个空格（`COMPONENT_MARK = "\u{2756} "`） |
| 改名时 | 只显示原名：前缀由静态绘制加，内联输入框里是文档里的真名，所以自动没有前缀 |

颜色（`label_ink`）：

| 状态 | 颜色 |
|---|---|
| 普通帧，未选中 / 常态 / 悬停 | 灰：浅色主题黑 26%（`from_black_alpha(67)`），深色主题同比例白 |
| 普通帧，选中 | 强调色 `app.accent()`（浅色页面上即更深一档，蓝 = `#007AE5`） |
| 组件 / 组件集 | **一直是** `#8638E5`，选中与否都不变 |
| 插槽 | `#FF24BD` |
| 图标层 | `#FFB34D` |

## 2. 尺寸框（选中框下方）

| 项 | 值 |
|---|---|
| 顶边 | 对象下边缘 + **9** |
| 水平 | 与对象水平居中 |
| 内边距 | 左右各 6、上下各 2 → 11 pt 文字时约 61×17 |
| 圆角 | 3 |
| 文字 | 11 pt，`W × H`（如 `205x203`） |
| 底色 | 对象身份色：普通帧 = 强调色，组件 / 组件集 = `#9747FF`，插槽 = `#FF24BD` |

## 3. 名称行右侧的两个 16×16 图标槽

两个槽都**水平右对齐到对象右边缘**，不跟随名称文字的长度，整块坐在对象上边缘外面
（与名称文字同一行）：

| 项 | 值 |
|---|---|
| 槽尺寸 | **16 × 16** |
| 最右槽（①）的右边缘 | 对象右边缘 **+ 2** |
| 槽**底边** | 对象上边缘 **− 6** |
| 两槽间距 | **2** |
| ② 的左边缘 | 对象右边缘 − 30（= ① 左边 − 2 − 16），纵向同 ① |
| 常态背景 | 透明 |

- **① 开发状态槽**（已做）：
  - **没有标签（常态）**：整块透明、**没有悬停态、没有图标、没有下拉菜单**；点一下直接置
    `devStatus: readyForDev`。但悬停这个位置**仍会让下面的框显示 hover 轮廓**（与悬停名称文字
    一样）。
  - **已置「待开发」**：常态绿 `#14AE5C` + 代码图标（`ui-code`，13×11）；悬停深一档绿
    `#009951` + 三个白点（圆角 3）。点一下在槽下方 **6** 弹出下拉菜单，菜单与槽水平居中，
    两项：`在开发模式中打开`（选中该对象 + 右栏切到开发）、`移除状态`（`devStatus: none`）。
    `Changed` / `Completed` 底色分别是 `#A75B00` / `#6E6E73`。
  - **未选中但已有标签**：点击 = 先选中这个框，再打开同一个下拉菜单。
- **② 预留位**（**未做**）：位置如上表，本轮不画内容、不接点击。以后要做时直接用
  `frame_labels::name_slots(x1, y0)[1]`，别重新量设计稿。
- 槽只在对象**选中**时绘制（有状态的除外，它一直显示底色）；未选中时不画、也不接点击。
- 已知限制：旋转帧的标签保持水平（GPUI 不能整体旋转已画出的图元），槽按对象包围盒定位，
  不随旋转走。

## 4. 变体组的「+」

| 项 | 值 |
|---|---|
| 尺寸 | 16 × 16 |
| 顶边 | 对象下边缘 + **30**（= 尺寸框 9 + 框高 17 + 4） |
| 水平 | 与对象水平居中（与尺寸框同一中心） |
| 外观 | 组件紫 `#9747FF` 底、圆角 3、白色 10×10 十字 |
| 显示条件 | 选中的**组件集**（`NodeKind::ComponentSet`） |
| 点击 | `component.addVariant { id }` |
